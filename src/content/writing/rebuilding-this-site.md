The old site was a one-page portfolio template: hero, about, jobs, project cards. It said who I am, but gave nothing worth coming back to.

This version is writing-first: a short home page, a place for posts, a list of prototypes, and an about page. It is a static [Astro](https://astro.build) site hosted on GitHub Pages, with search built at deploy time and no tracking beyond basic analytics.
